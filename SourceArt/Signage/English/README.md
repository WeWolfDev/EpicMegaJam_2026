# Signage — English edition

34 supplied images mapped to the existing T_Senal_* texture paths. Actor positions and gameplay references are preserved. Material image-aspect parameters were updated to the supplied file proportions.

The last supplied batch still used Spanish on two power cards. Those labels were localized to BOUNCE and PULL with the built-in image generation tool. The power cards now use M_PowerSign_Readable: masked, two-sided with corrected back-face UVs and unlit to avoid direct-light overexposure.

PNG sources are kept in this directory. Previous Unreal assets are backed up in work/signs_english/backup in the chat workspace. Verification: 34 textures and all 34 material families updated; visual inspection of arrival, advertising and both power cards.
